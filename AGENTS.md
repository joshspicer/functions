# Agent Instructions

This document provides instructions for AI agents (like Claude Code, GitHub Copilot, etc.) working on this repository.

## Testing the Index Function Output

After making changes to the index page logic, you should **always** run the test script to verify the output and append it to your response so the maintainer can see exactly what it looks like in a terminal.

### Quick Test Command

```bash
npm run build && node scripts/test-index.js
```

### What to Include in Your Response

When you make changes to any of these files:
- `src/lib/indexHelpers.ts`
- `src/functions/index.ts`
- `scripts/test-index.js`

You **must**:
1. Build the TypeScript: `npm run build`
2. Run the test script: `node scripts/test-index.js`
3. Capture the complete output including ANSI color codes
4. Render or display the output in a way that shows what it would look like in a terminal
5. Append this output at the end of your response/commit message

### Example Workflow

```bash
# 1. Make your changes to src/lib/indexHelpers.ts

# 2. Build
npm run build

# 3. Test and capture output
node scripts/test-index.js

# 4. Include the output in your response with a note like:
# "Here's what the terminal output looks like after the changes:"
```

### Using Tools to Render Terminal Output

The test script produces ANSI-colored output. To properly display this:

- **For screenshots**: Use a tool like `script` or capture the terminal directly
- **For CI/CD**: The GitHub Actions workflow captures this automatically in job summaries
- **For async iteration**: Check the workflow run output in GitHub Actions
- **In VS Code**: The integrated terminal renders ANSI codes automatically

### Automated Workflow

A GitHub Actions workflow (`test-index-output.yml`) runs automatically when you push changes to:
- `src/lib/indexHelpers.ts`
- `src/functions/index.ts`
- `scripts/test-index.js`

The workflow output appears in:
1. The workflow run logs
2. The job summary (with formatted output)

## Key Files

- **`src/lib/indexHelpers.ts`**: Core logic functions (testable)
- **`src/functions/index.ts`**: Azure Functions handler (thin wrapper)
- **`scripts/test-index.js`**: Standalone test script
- **`dist/src/lib/indexHelpers.js`**: Compiled JavaScript (generated by `npm run build`)

## Testing Philosophy

The index function logic has been split to enable:
1. **Quick iteration**: Test without Azure Functions runtime overhead
2. **Visual feedback**: See exactly what terminal users will see
3. **Async collaboration**: Agents can make changes and show output without manual testing
4. **Editor integration**: VS Code and other editors can run tests inline

## For GitHub Copilot

When making changes to the index page:
1. Always build and test after edits
2. Include the rendered terminal output in comments or PR descriptions
3. Verify ANSI colors render correctly
4. Check that ASCII art displays properly
